# NeuroGraph Agent — Dashboard Instructions

> **Disclaimer:** NeuroGraph Agent is a research intelligence prototype.
> Outputs are computationally derived, hypothesis-generating, and
> **not clinical decision support.**

---

## How to Run

From the project root directory (`NeuroGraph/`):

```bash
streamlit run app.py
```

The dashboard will open in your browser at `http://localhost:8501`.

---

## What the Dashboard Shows

| Page | Content |
|------|---------|
| **Overview** | Key metrics, pipeline summary, top gap candidates, score distribution figures |
| **Gap Candidates** | Filterable table and charts of all 499 scored targets by gap_interpretation_tier |
| **Target Explorer** | Evidence card, matching papers, and matching trials for any selected target |
| **Themes** | NMF topic sizes, top terms, and paper/trial browsers for each theme |
| **Knowledge Graph** | Graph metrics, static subgraph figures, and interactive target edge explorer |
| **Reports & Downloads** | Download buttons for all processed CSVs, graph files, and markdown reports |
| **Methodology & Limitations** | Data sources, analytical methods, and full limitations |

## Important Limitations

- All findings are computationally derived from a corpus sample (478 papers, 1,000 trials).
- High gap scores are hypothesis-generating signals, not therapeutic recommendations.
- Trial registrations may not explicitly mention molecular target symbols.
- Gene symbol matching is lexical and may produce false positives for ambiguous symbols.
- Open Targets association scores are not proof of therapeutic viability.
- Expert biomedical review is required before any finding can inform research decisions.
- This tool is **not clinical decision support**.
